# Learning-cpp
A repository dedicated to learning the fundamentals of C++ programming.

Hello! 
This repository is being used to practice syntax, solve algorithms, and track my growth & proficiency over time.

The code written in this repository will be created in tandem with lessons learned from the book "*Think Like a Programmer - An introduction to creative problem solving*" (2012) by *V. Anton Spraul.*

As stated by the book, it teaches readers how to:

• *Split problems into discrete components to make them easier to solve*

• *Make the most of code reuse with functions, classes, and libraries*

• *Pick the perfect data structure for a particular job*

• *Master more advanced programming tools like recursion and dynamic memory*

• *Organize your thoughts and develop strategies to tackle particular types of problems*
