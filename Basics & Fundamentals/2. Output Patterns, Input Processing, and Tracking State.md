Problem: Half of a Square
	- Task: Write a program using two output statements producing a pattern of hash symbols shaped like half of a square (5 x 5 square, cut into a right triangle).

Solution:

	#include <iostream>
	using std::cout;
	using std::cin;
	
	int main () {
	    
	    for (int row = 1; row <= 5; row++){
	        for (int hashNum = 1; hashNum <= 6 - row; hashNum++){
	            
	            cout << "#";
	            
	        }
	        cout << "\n";
	    }
	    return 0;
	}

Output:

	#####
	####
	###
	##
	#

Problem: Count down by counting up
	- Task: Program should display 5 through 1, each number being on a separate line.

Solution (In-work):

	for (int hashNum = 1; hashNum <= 5; hashNum++){
		cout << 6 - hashNum << "\n";
	}
	cout << "\n";

Output:

	5
	4
	3
	2
	1
