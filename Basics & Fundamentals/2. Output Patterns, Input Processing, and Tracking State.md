Output Patterns
============================================================================

(1) Problem: Half of a Square

	- Task: Write a program using two output statements ("cout << '#'" and "cout << '\n'") producing a pattern of hash symbols shaped like half of a square (5 x 5 square, cut into a right triangle).

Solution:

	#include <iostream>
	using std::cout;
	using std::cin;
	
	int main () {
	    
	    for (int row = 1; row <= 5; row++){
	        for (int hashNum = 1; hashNum <= 6 - row; hashNum++){
	            
	            cout << "#";
	            
	        }
	        cout << "\n";
	    }
	    return 0;
	}

Output:

	#####
	####
	###
	##
	#

(2) Problem: Count down by counting up
	
	- Task: Write a program that should display 5 through 1, each number being on a separate line.

Solution:

	for (int hashNum = 1; hashNum <= 5; hashNum++){
		cout << 6 - hashNum << "\n";
	}
	cout << "\n";

Output:

	5
	4
	3
	2
	1

----------------------------------------------------------------------------

(3) Problem: A sideways triangle
	
	- Task: Write a program using two output statements ("cout << '#'" and "cout << '\n'") producing a pattern of hash symbols shaped like a sideways triangle.

Solution (in work):

	#include <iostream>
	using std::cout;
	using std::cin;
	
	int main () {
	    
	    for (int row = 1; row <= 7; row++){
	        for (int hashNum = 1; hashNum <= 4 - abs(4 - row); hashNum++){
	            
	            cout << "#";
	            
	        }
	        cout << "\n";
	    }
	    return 0;
	}

Output:

	#
	##
	###
	####
	###
	##
	#

Notes:

	Using the abs() will give you the absolute number of a provided integer, great for situations where you need to count up and then down like this.
